面试常见度】⭐⭐⭐⭐⭐（必考，面试官绝对会问“介绍一下你的项目”）

1. 什么是 STAR 法则？
这是面试官用来判断你项目是否真实、你是否思考过的黄金标准。

·S (Situation) 背景：项目的起因是什么？例如：“因为参加学校软件设计大赛需要，或者为了解决实验室论文数据整理麻烦”。

·T (Task) 任务：你在项目里负责的具体任务是什么？例如：“我负责后端 API 开发和数据库表结构设计”。

·A (Action) 行动（最关键！）：你具体怎么做的？例如：“我用了 Spring Boot 搭建框架，为了解决高并发查询，我给 Redis 加了缓存，并设置了过期时间避免雪崩。” （这里一定多谈技术细节！）

·R (Result) 结果：最好量化！例如：“优化后，接口响应耗时从 3 秒降低到了 200 毫秒，QPS 提升了 50%”。

2. 切忌“背简历”
不要对着简历念“我做了 XX 系统，用了 SSM 框架”。请用 STAR 法则像讲故事一样说出来，讲到 Action 的时候，面试官会顺着你的话术深挖下去。
